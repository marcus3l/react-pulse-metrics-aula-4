# Pulse Metrics — painel de campanhas e métricas

Protótipo de uma plataforma de analytics de marketing para acompanhar campanhas, audiência, resultados, relatórios e equipes. Esta pasta registra uma etapa posterior do projeto Pulse Metrics, com módulos de dashboard e gerenciamento.

## Destaques

- Painéis de campanhas, métricas e segmentos de audiência
- Relatórios, filtros, exportação e visualizações de dados
- Telas de equipe, permissões, integrações e configurações
- Dados locais de demonstração e testes automatizados

## Tecnologias

React, TypeScript, Vite, Redux Toolkit, Chart.js, Tailwind CSS, Jest e Puppeteer. A pasta `api` contém um serviço em Go.

## Como executar

Requer Node.js e Go instalados.

```bash
npm install
npm run dev:full
```

Para iniciar separadamente, use `npm run dev` para o front-end e `npm run api` para a API. Execute os testes com `npm test`.

## Dados de demonstração

Os usuários e métricas são fictícios e servem apenas para demonstração local. Credenciais presentes nos testes não são contas reais.

## Contexto

Projeto educacional em evolução; esta pasta representa uma etapa específica do curso.
